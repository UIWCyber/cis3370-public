Fields Are Numbered

The basic move
$ awk '{print $1, $5}' auth.log# column 1 and column 5
09:14:22 sshd
$ awk '{print $NF}' auth.log# NF is the number of fields, so $NF is the last one
51022
DefinitionA field is one whitespace-separated chunk of a line. $0 is the whole line, $1 the first field, $NF the last.

Pattern, Then Action

  • The form is awk 'PATTERN { ACTION }'. Either half can be left out.
  • No pattern means every line. No action means print the line.
Three equivalent ideas
$ awk '/Failed/' auth.log# pattern only: print matching lines
$ awk '/Failed/ {print $NF}' auth.log# pattern and action
$ awk '$3 == "sshd" {print $0}' auth.log# compare a field, not the whole line

Counting Is Where It Gets Useful

How many failures, and from where
$ awk '/Failed password/ {c++} END {print c}' auth.log
418
$ awk '/Failed password/ {ip[$(NF-3)]++} END {for (i in ip) print ip[i], i}' auth.log
211 203.0.113.14
64 198.51.100.7
DefinitionAn associative array in awk maps a string to a number. ip[x]++ counts occurrences of x without you declaring anything.

Ranking: awk Plus Two Old Friends

Top five noisiest sources
$ awk '/Failed password/ {ip[$(NF-3)]++} END {for (i in ip) print ip[i], i}' auth.log \
| sort -rn | head -5
  • awk counts. sort -rn orders. head trims.
  • This three-part pipeline answers most first-pass collection questions.

When Whitespace Is Not the Delimiter

Comma and colon separated data
$ awk -F',' '{print $2}' flows.csv# -F sets the input field separator
$ awk -F':' '$3 >= 1000 {print $1}' /etc/passwd# non-system accounts
Tip-F'\t' for tab separated. Set OFS if you want the output separated differently from the input.

Network Data Is the Same Problem

Connection records: who talked to whom, and how much
$ awk '{bytes[$3" -> "$5] += $8} END {for (p in bytes) print bytes[p], p}' conn.log \
| sort -rn | head
4823911 10.0.0.14 -> 203.0.113.14
88214 10.0.0.9 -> 198.51.100.7
  • Same three moves: key it, accumulate it, rank it.
  • The only thing that changed is which fields carry meaning.

Things That Will Bite You

  • Field numbers shift when a message has a different word count. Anchor on a pattern, not a position, when you can.
  • Quoted fields containing spaces are not handled by whitespace splitting.
  • awk sees rotated logs as separate files. Check whether you are counting a day or a fragment.
  • A count with no time window is not a finding. Always state the period.
